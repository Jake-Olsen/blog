Trying the Satisfactory Game Server API

I've gotten familar with APIs at work and thought I'd try out the Satisfactory Game API that is available for self-hosted dedicated servers. The port needs to be open afaik to allow the game tto work as well. Otherwise if not I might just lock it down more on the router's firewall if that ends up not being the case. On the wiki https://satisfactory.wiki.gg/wiki/Dedicated_servers . There is great simple instructions to setup the server. There is also resources on this page that refer to the API documentation: https://satisfactory.wiki.gg/wiki/Dedicated_servers/HTTPS_API https://github.com/satisfactory-oas/spec I was API was easier to use than I expected. I was able to create a client password and update the admin password for the server. It uses a bearer token for authentication. I encountered a strange issue with the downloaded template. Specifically the minimumPrivilegeLevel needs to be NotAuthenticated otherwise it will have issues.
