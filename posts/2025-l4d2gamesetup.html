Personal Setup & Recommendations

Autoexec.cfg for Game

I'd recommend having an autoexec.cfg file for auto applying settings, and alias shortcuts for commands. It can be found here:
steamapps/common/Left 4 Dead 2/left4dead2/cfg/autoexec.cfg.
Here is part of my autoexec.cfg below: 

fps_max 144
echo "Max Frames Per Second set to 144"
mm_dedicated_force_servers 123.456.789.123:98765:192.168.1.4:98765
echo "Automatically Set to 96% Vanilla Dedicated Server upon launching game"

alias "96vanilla-search" "mm_dedicated_force_servers 123.456.789.123:98765:192.168.1.4:98765"
echo" ----------------------------------------------------"
echo" alias connection cmds"
echo" 96vanilla-search -----force non-official dedicated server search to Jake's Server IPs"

alias "startj" "sm_give machete; sm_give hunting_rifle;"
echo  "startj for quick loadout"

This will automatically after launching the game, cap my fps to 144 and set my own dedicated server I setup. echo just writes it to the dev console in game. I use it for leaving myself notes that I can access in-game to refer to server commands and switch alternate game servers I have.

Here is a scenario of why I use this: Friends want to play L4D2 on a good server in our region without lag or crazy mods? I can just launch L4D2 from Steam as normal, create lobby, click "Best Available Dedicated", create lobby, they join, we play. Quick and Easy.

Instant mod load upon game startup.

This can especially help if you have lots of skins and various mods. As the game will attempt to check every single mod at launch for any steam workshop updates. If you don't wait for that load, your mods will be skipped and won't be loaded when you join into a match.

To fix this:
  1. Move all the mod files into the addons folder instead of addons/workshop folder
    • Steam/steamapps/common/Left 4 Dead 2/left4dead2/addons/
  2. Then unsubscribe them from the steam workshop.
Notes:
  • This changes results in a nearly instant load in L4D2.
  • The downside is you won't automatically get updates for your mods. However it's 2025 most aren't getting updated.
  • I would highly recommend manually backing up your mods.
  • One option is to note down the links. Either in a text file, bookmarks, ect
    • (tip: opening all in a web browser, then using OneTab chrome extension can make quick work of this)
  • Additionally you can backup your addon folder.
    • (NAS, SMB Samba Share, External Drive, Cloud Storage, ect)
  • In the example below I kept the Steam Workshop ID in the filename instead of keeping links.

Linux Specific Fixes (Optional)

I manually download fonts and tried to fix the font errors that appear in the main menu. I'm not sure why they don't download with the game or why they were excluded. Verifying files doesn't fix this.

I just found these online and downloaded them into the linux_fonts folder Steam/steamapps/common/Left 4 Dead 2/left4dead2/resource/linux_fonts DejaVuSans-BoldOblique.ttf DejaVuSans.ttf LiberationSans-Regular.ttf DejaVuSans-Bold.ttf LiberationMono-Regular.ttf marlett.ttf DejaVuSans-Oblique.ttf LiberationSans-Bold.ttf

I also for some odd reason also had to place a 2nd copy of marlett.ttf into the resource folder to get the error to go away. Steam/steamapps/common/Left 4 Dead 2/left4dead2/resource/

There is an issue with the vocalizer menu in-game. It won't default to the center, it also feels quite odd. Its like trying to shift a manual transmission car rather than an easy radial wheel. This is a known issue (Refer to #558) that probably won't be fixed. Running the windows version of the game fixes this, but you'll have issues joining public server and private servers. I just got used to not depending on it for in-game character callouts like weapon here, health kit here, ect. Just use chat or your mic.

Another known issue (Refer to #1881 & #2000 ) is that the audio type in L4D2 is set as 5.1 Surround Sound. If you have another type such as headphones, you have to set it to headphones on every single launch of the game. There is unfortunately no known workarounds and no console command that works with L4D2. This is stated directly on Valve's Wiki: developer.valvesoftware.com/wiki/Snd_surround_speakers
"Note: This command is not available in Left 4 Dead 2."
