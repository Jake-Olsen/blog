Tools I Like, alternatives, and tools I've previously used but don't anymore

Neovim
  • Text Editor that can be used in terminal and ssh sessions
  • Crossplatform support for Linux, Windows, and Mac
  • Quickly edit documents, config files, ect with a heavy emphasis on keyboard for max efficiency and precise editing.
it-tools.tech
  • Self-Hosted collection of handy online tools for devs, with great web UX.
  • https://github.com/CorentinTh/it-tools
Obsidian
  • Markdown Note Taking Application. Quick and easy, it also keeps your notes, images, files easily readable, migratable, ect. I used it to write most of the recent articles and guides. Just used it-tools to convert this markdown into html.
Excalidraw
  • A whiteboard for quickly sketching out ideas and plans. Easy to use, keyboard shortcuts.
AlternativeTo.net
  • website to find alternative apps and services
  • It has filters, user voting and comments, and more
Ventoy
  • Load up multiple ISOs, and Disk Images onto 1 USB Drive.
  • It allows you to keep files on your usb drive and you can just toss most ISOs into a folder and they will become bootable.

Misc Cross-Platform Apps:

  • KeePass 2 (Password Manager)
  • Bitwarden (Password Manager, I no longer use personally but it is good)
  • Handbrake (Convert & Optimize videos to be smaller storage size for uploading)
  • Postman Enterprise (Good if you pay for it, free version isn't good now)
  • Hoppscotch (Postman Alternative that works for me thus far, open source, free, desktop apps, web app, self hosted optionally)

Linux Tools:

  • Alacritty (Terminal Emulator, but anything that works is fine.)
  • cloud-guest-utils (contains tools to help expand virtual machine drives)
  • fzf (interactive tui to easily search and go to files, folders, ssh configured servers)
  • ripgrep (really fast way to find text in an unknown file)
  • neovim (text based editor, nicer newer vim)
  • vim (text based editor)
  • rsync (Sync files between computers and folders)
  • htop (Resource Task Monitor Manager)
  • btop (Resource Task Monitor Manager)
  • ufw (Uncomplicated FireWall to open and close ports on the machine)
  • wget (download files from network)
  • curl (download files from network)
  • tar (unzip/uncompress archives)
  • tealdeer (short cheatsheet for common commands, not replacement for manual pages)
  • tmux (keeps remote session active, terminal multiplexer)
  • byobu (tmux wrapper)
  • Wireshark(Network Capture and Analysis)
